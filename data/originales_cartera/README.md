# Informes originales de Cartera (referencia)

Estos son los Excel **oficiales de Cartera**, no los generados por el programa.
Se usan como fuente de verdad del histórico Abr → May → Jun → Jul.

| Archivo | Corte |
|---------|--------|
| `abril_V1.xlsx` | Abril 2026 |
| `mayo_V1.xlsx` | Mayo 2026 |
| `junio_V1.xlsx` | Junio 2026 |
| `julio_V1.xlsx` | Julio 2026 |

La plantilla activa (`templates/plantilla_informe_cartera.xlsx`) se sembrÓ
desde **julio_V1**, con columnas:

**ABRIL → MAYO → JUNIO → JULIO** (valores fijos)

Así, al generar **agosto**, el programa apila AGOSTO sin perder los meses previos.
